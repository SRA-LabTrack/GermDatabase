READ-ONLY USE
-------------
The complete workbook history is bundled into the site, so searching works
even before the Appwrite import.

SYNC ALL 2,293 RECORDS TO APPWRITE
------------------------------------------------------------
1. Copy your normal .env into this folder.
2. Temporarily add:
     APPWRITE_API_KEY=YOUR_TEMPORARY_SERVER_KEY
3. Run:
     npm.cmd install
     npm.cmd run setup:combinations
4. Wait for:
     ✓ Combination Registry workbook import complete.
5. Revoke/delete the temporary APPWRITE_API_KEY.
6. Start:
     npm.cmd run dev

setup:combinations is idempotent. It uses deterministic source-position IDs,
so running it again does not duplicate the workbook records.

Manual combination entries remain separate and editable.
Workbook-source records are protected from deletion in the UI.
