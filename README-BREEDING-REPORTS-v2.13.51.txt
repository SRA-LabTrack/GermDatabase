CaneSprout v2.13.51 — Breeding Reports

Adds on-demand breeding activity reports inside Combination Registry.

REPORT PERIODS
- Weekly: Monday through Sunday for the selected week.
- Monthly: selected calendar month.
- Quarterly: Q1, Q2, Q3, or Q4 for the selected year.
- Annual: selected calendar year.

WHO CAN USE IT
- Regular CaneSprout users
- Administrators

DATA INCLUDED
- Audited bundled Combination Registry history
- Locally registered manual combinations
- Optional live cloud manual combinations when online
- Workbook source-date text is preferred when it can be parsed, so historical
  reports are not distorted by an imperfect normalized date.

TECHNICAL REPORT OPTION
Turn on "Include Technical Report" before Generate report. The request can include:
- Technical report title
- Prepared by
- Objective
- Methodology / Basis
- Observations / Findings
- Recommendations

Activity statistics are computed from the breeding records; narrative technical
fields remain user-entered.

OUTPUT
- On-screen breeding activity table and metrics
- Download HTML
- Print / Save PDF through the browser

APPLY
1. Extract this ZIP directly into the CaneSprout project root.
2. Run APPLY-BREEDING-REPORTS-v2.13.51.cmd
3. Run npm.cmd run verify:breeding-reports
4. Run npm.cmd run build
