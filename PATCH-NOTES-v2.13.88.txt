IMPORTANT SAFETY BEHAVIOR
-------------------------
The updater first performs a live preflight. If an existing identity is ambiguous and cannot be tied to a
specific workbook source row, the patch stops BEFORE writing anything. It also checks required Appwrite
attributes and configured string sizes before writing.

HOW TO APPLY
------------
1. Extract the contents of this ZIP directly into the CaneSprout v2.13.87 project root.
2. Make sure the temporary Appwrite API key is available in .env or .env.local.
3. Double-click APPLY-GERMPLASM-WORKBOOK-UPDATE-v2.13.88.cmd.
4. The script runs a dry-run/preflight first. Only if it passes does it perform the live upsert.
5. Review reports/germplasm-workbook-update-v2.13.88.json after completion.

The patch is designed to be rerun safely. It does not auto-delete or auto-merge conflicting historical observations.
