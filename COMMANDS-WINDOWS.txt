CANESPROUT REGISTRY v2.1.5 - WINDOWS COMMANDS
=============================================

IMPORTANT
These commands are for Windows CMD, so they deliberately use npm.cmd.
Vercel runs Linux and must keep plain npm in vercel.json.

FIRST INSTALL / AFTER PACKAGE CHANGES
npm.cmd install

ONE-TIME APPWRITE SPLIT-SCHEMA SETUP + 933-ROW SEED
npm.cmd run setup:appwrite
Requires a TEMPORARY APPWRITE_API_KEY in .env.
Revoke it immediately after setup succeeds.

RUN LOCALLY
npm.cmd run dev
Open: http://localhost:5174

BUILD WEBSITE
npm.cmd run build

PREVIEW PRODUCTION BUILD
npm.cmd run preview

RUN ELECTRON DESKTOP DEV
npm.cmd run desktop:dev

BUILD WINDOWS INSTALLER
npm.cmd run desktop:build:win
