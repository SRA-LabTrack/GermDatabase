CANESPROUT REGISTRY v2.3.0 - WINDOWS COMMANDS
=============================================

IMPORTANT
These commands are for Windows CMD, so they deliberately use npm.cmd.
Vercel runs Linux and must keep plain npm in vercel.json.

FIRST INSTALL / AFTER PACKAGE CHANGES
npm.cmd install

RUN LOCALLY
npm.cmd run dev
Open: http://localhost:5174

BUILD WEBSITE
npm.cmd run build

PREVIEW PRODUCTION BUILD
npm.cmd run preview

APPWRITE SETUP
npm.cmd run setup:appwrite
Only needed for a fresh Appwrite project/schema. v2.3.0 adds no new attributes or indexes,
so an existing working v2.1.5+ database does NOT need setup again.

RUN ELECTRON DESKTOP DEV
npm.cmd run desktop:dev

BUILD WINDOWS INSTALLER
npm.cmd run desktop:build:win
