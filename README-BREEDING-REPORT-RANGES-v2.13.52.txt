CaneSprout v2.13.52 — Multi-Year Breeding Report Time Ranges

NEW REPORT COVERAGE
1. Single period
   - Weekly
   - Monthly
   - Quarterly
   - Annual

2. Time period range
   - Select a Start year and End year
   - Select how the entire range should be broken down:
     Weekly / Monthly / Quarterly / Annual

EXAMPLE
Start year: 2026
End year:   2027
Break down by: Weekly

CaneSprout generates one continuous weekly timeline across the whole
2026–2027 period. Every calendar week is included, even if that week has
zero recorded crosses. Weeks crossing the year boundary remain a single
continuous weekly interval.

The report displays:
- Overall crosses
- Overall unique pairings
- Female and male parents
- Breeding days
- Total reporting intervals
- Active reporting intervals
- A full interval table showing every week/month/quarter/year
- Detailed recorded combination events
- Optional Technical Report, unchanged from v2.13.51

APPLY
1. Extract this ZIP directly into the CaneSprout project root.
2. Run APPLY-BREEDING-REPORT-RANGES-v2.13.52.cmd
3. Run:
   npm.cmd run verify:breeding-report-ranges
   npm.cmd run verify:breeding-reports
   npm.cmd run build
